ABBREVIATIONS / 약자
════════════════════════════════════════════════════════════════════════════════

DWT  : Discrete Wavelet Transform (이산 웨이블릿 변환)
DFS  : Doppler Frequency Spectrum (도플러 주파수 스펙트럼)
SDP  : Spatial Doppler Profile (공간 도플러 프로필)
MLP  : Multi-Layer Perceptron (다층 퍼셉트론)
PCA  : Principal Component Analysis (주성분 분석)
STFT : Short-Time Fourier Transform (단시간 푸리에 변환)
ACF  : Auto-Correlation Function (자기상관함수)
CSI  : Channel State Information (채널 상태 정보)
FFT  : Fast Fourier Transform (고속 푸리에 변환)
CV   : Cross-Validation (교차 검증)
L2   : L2 정규화 (가중치 감소)

DECISION TREE: 어떤 파라미터를 먼저 조정할까?
════════════════════════════════════════════════════════════════════════════════

성능이 낮다면? (80% 이하)
  → 1️⃣ Hampel Filter 상태 확인
  → 2️⃣ DWT level 증가 (10 → 12)
  → 3️⃣ n_pca 증가 (6 → 12)
  → 4️⃣ MLP hidden_layers 증가 (256,128,64 → 512,256,128)

성능은 좋지만 느리다면? (85% 이상, 5분 이상)
  → 1️⃣ level 감소 (10 → 8)
  → 2️⃣ n_pca 감소 (6 → 4)
  → 3️⃣ hidden 축소 (256,128,64 → 128,64,32)

성능이 불안정하다면? (CV Std > 0.02)
  → 1️⃣ target_fs 변경 시도 (100 → 50)
  → 2️⃣ hampel_window 조정 (7 → 5 또는 9)
  → 3️⃣ 데이터 확인 (이상 샘플 있는지)

특정 클래스가 잘 분류되지 않는다면?
  → 1️⃣ Confusion Matrix 분석
  → 2️⃣ n_pca 증가 (특징 정보량 확대)
  → 3️⃣ hidden_layers 구조 변경 (깊이/폭 조정)
